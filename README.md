# Seanime Custom Anime Catalog

An experimental AniList-powered anime catalog provider for Seanime.

## Features
- Search anime using AniList GraphQL.
- Exclude adult anime.
- Display English or Romaji titles.
- Indonesian provider metadata.

## Limitations
- Episode listing is not implemented.
- Video playback is not implemented.
- Dub filtering is not supported.

## Build

npm install
npm run build

## Status

Early development.
